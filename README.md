# Actividad 8: Adivina el Número con Vite
## Módulo 3: Creación de Proyectos Modernos con Vite y Vanilla JS

### 📖 Descripción del Proyecto
Juego interactivo "Adivina el Número" construido sobre el entorno de desarrollo ultrarrápido **Vite** utilizando **Vanilla JavaScript (ES Modules)** y **CSS3**. Genera un número secreto aleatorio del 1 al 100 y guía al usuario con pistas contextuales hasta acertar.

### 🎯 Objetivos Cubiertos
- [x] Configuración de proyecto con Vite (`npm create vite@latest`).
- [x] Manejo de dependencias y scripts de desarrollo (`dev`, `build`, `preview`).
- [x] Importación nativa de estilos vía ES Modules (`import './style.css'`).
- [x] Manipulación eficiente del DOM y escucha de eventos (`click`, `keydown`).
- [x] **Funcionalidades avanzadas adicionales:**
  - Contador reactivo de intentos.
  - Historial visual clasificado con etiquetas coloreadas (muy alto / muy bajo / acierto).
  - Soporte de envío con tecla Enter.
  - Botón de reinicio completo sin recargar el navegador.
